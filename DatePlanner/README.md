# Вечір — планер побачення

Мобільна анкета для планування побачення: свайпи з їжею та активностями, вибір місця на карті, готове повідомлення для Telegram.

## Можливості

- Базова інформація: ім'я, Instagram, Telegram, місто
- Свайп-картки: їжа (піца, суші, кафе…), активності (кіно, прогулянка…), атмосфера
- Вибір дати та часу
- Карта з місцями зустрічі (Київ, Львів, Одеса)
- Готовий текст плану — копіювання та відправка в Telegram

## GitHub Pages

### Автоматичний деплой

Після merge в `master` workflow `.github/workflows/deploy-date-planner.yml` публікує папку `DatePlanner` на GitHub Pages.

**Налаштування репозиторію (один раз):**

1. Settings → Pages
2. Source: **GitHub Actions**
3. Після першого успішного деплою сайт буде доступний за адресою:

```
https://denyspiven.github.io/My-Projects/
```

### Локальний перегляд

```bash
cd DatePlanner
python3 -m http.server 8080
```

Відкрий `http://localhost:8080`

## Як користуватись

1. Відкрий сайт на телефоні
2. Заповни імена та Telegram одержувача
3. Пройди свайпи (вправо — так, вліво — ні)
4. Обери дату, час і місце на карті
5. Скопіюй план або натисни «Написати в Telegram»
